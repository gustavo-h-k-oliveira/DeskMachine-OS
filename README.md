# 🖥️ DeskMachine-OS

Um portfólio interativo que simula a experiência de um sistema operacional clássico (estilo Windows 95/98) diretamente no navegador.

---

## 🚀 Tecnologias Utilizadas

- **[React](https://react.dev/)**: Biblioteca para construção da interface de usuário.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build rápida e ambiente de desenvolvimento.
- **[Zustand](https://github.com/pmndrs/zustand)**: Gerenciamento de estado global das janelas e tarefas.
- **[react-rnd](https://github.com/bokuweb/react-rnd)**: Componente para arrastar e redimensionar janelas.
- **[react-terminal](https://github.com/bony2023/react-terminal)**: Simulação de terminal interativo com comandos customizados.
- **CSS3**: Estilização retro com suporte a design responsivo.

---

## ✨ Funcionalidades

- 💻 **Tela de Boot Clássica**: Animação de inicialização retro com efeito sonoro.
- 🪟 **Gerenciador de Janelas**: Sistema com foco, arrastar, redimensionar, minimizar, maximizar e fechar janelas.
- 🌐 **Web Browser**: Navegador simulado com páginas de apresentação, experiências profissionais e contatos.
- 📝 **Bloco de Notas (Notepad)**: Visualização de informações sobre trajetória e formação acadêmica.
- 📟 **Terminal Interativo**: Terminal funcional com comandos como `help`, `whoami`, `ls`, `ping`, `date` e exibição de habilidades técnicas.
- 📱 **Suporte a Dispositivos Móveis**: Ajuste automático para janelas maximizadas e controles adaptados para toque.

## 📦 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado na versão LTS.

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/gustavo-h-k-oliveira/DeskMachine-OS.git
   cd DeskMachine-OS
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abra no navegador:**
   Acesse a URL exibida no terminal (geralmente `http://localhost:5173/DeskMachine-OS/`).

---

## 🛠️ Scripts Disponíveis

- `npm run dev`: Inicia o servidor local de desenvolvimento com Vite.
- `npm run build`: Gera o build de produção otimizado na pasta `dist`.
- `npm run preview`: Executa localmente o build de produção para testes.
